\section{Overview}

This report presents a comprehensive comparison of robot control performance across different:
\begin{itemize}
  \item Controllers: FBL (Feedback Linearization) and PBC (Passivity-Based Control)
  \item Uncertainty levels: high, extreme
  \item Initial conditions: matched vs mismatched
  \item Gain tuning: optimized vs unoptimized
  \item Trajectory types: quintic, bang-bang, bang-coast-bang
\end{itemize}

Total simulations analyzed: 96
